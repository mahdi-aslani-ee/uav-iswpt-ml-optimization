راهنمای فایل‌های پروژه UAV-ISWPT + ML
=====================================

فایل اصلی برای بررسی و اجرا
---------------------------

02_Complete_ML_Analysis.ipynb
    نوت‌بوک اصلی پروژه و مهم‌ترین فایل تحویلی است.
    همه‌ی ماژول‌های Python به‌صورت سلول‌های قابل مشاهده‌ی %%writefile داخل آن
    قرار دارند؛ بنابراین کد مخفی یا وابستگی گم‌شده ندارد.

    شامل:
    - مدل فیزیکی Kang؛
    - حل دقیق SDP برای ارتفاع ثابت؛
    - Algorithm 1 و Algorithm 2 مقاله‌ی Kang؛
    - ممیزی حل‌گر و برچسب‌ها؛
    - پیش‌پردازش داده؛
    - Linear Regression، Decision Tree، RBF-SVR و MLP؛
    - انتخاب ابرپارامتر فقط با داده‌ی آموزش؛
    - پنج تقسیم مستقل؛
    - ارزیابی شکاف تابع هدف؛
    - مقایسه‌ی مستقیم با Figure 3a مقاله‌ی Kang؛
    - تولید نمودارها و آزمون نهایی ادعاها.

    برای ارائه یا بررسی سریع، سلول‌ها را از ابتدا به ترتیب اجرا کنید.
    گزینه‌های محاسبات طولانی با RUN_* = False غیرفعال هستند؛ نتایج ذخیره‌شده
    خوانده و نمایش داده می‌شوند.


فایل تولید دیتاست
-----------------

01_Dataset_Generation.ipynb
    فقط برای تولید یا ادامه‌ی تولید دیتاست است و کد ML ندارد.
    شامل مدل Kang، حل‌گر سریع، نمونه‌برداری بذرگذاری‌شده، جست‌وجوی ارتفاع،
    ذخیره‌ی مرحله‌ای و آزمون صحت داده است.

    برای بررسی پروژه لازم نیست دیتاست را دوباره تولید کنید.
    فقط در صورت نیاز به تولید نمونه‌ی جدید، RUN_ONE_CHUNK=True شود و نوت‌بوک
    به‌صورت مرحله‌ای اجرا گردد.


فایل‌های داده و نصب
-------------------

ds3.npz
    دیتاست اصلی و دقیق مورد استفاده‌ی کد: 1000 نمونه، 8 ویژگی، برچسب ارتفاع
    و مقدار تابع هدف.

dataset.csv
    نسخه‌ی قابل مشاهده‌ی همان دیتاست برای Excel یا بررسی دستی.

requirements.txt
    کتابخانه‌های لازم. نصب پیشنهادی:

    python -m pip install -r requirements.txt


پوشه‌های نتایج؛ کد نیستند
--------------------------

ml_corrected_outputs/
    خروجی نهایی ML شامل JSON نتایج، معیارهای پنج تقسیم و نمودارهای parity،
    gap distribution، MAE-vs-gap و permutation importance.

gap1_outputs_paper_grid/
    نتایج اصلی مقایسه با مقاله روی شبکه‌ی زاویه‌ی 0.1 درجه‌ی Kang، شامل
    CSV/JSON پنج روش و شکل‌های مقایسه‌ی objective و altitude.

gap1_outputs/
    ممیزی‌های تکمیلی روی شبکه‌ی 1 درجه، کیفیت حل‌گر، کیفیت برچسب و حساسیت
    تفکیک زاویه.


ماژول‌های کدی که داخل نوت‌بوک اصلی ساخته می‌شوند
-------------------------------------------------

kang.py
    مدل سیستم و معادلات Kang؛ هیچ کد ML ندارد و نسخه‌ی محافظت‌شده است.

fast.py
    حل‌گر تقریبی سریع برای تولید انبوه برچسب و oracle مشترک.

reference_solver.py
    حل دقیق CVXPY برای P2|h؛ مسئله هم DCP و هم DPP است.

algorithm2.py
    پیاده‌سازی Algorithm 2، Eq. (37)، P7 و Eqs. (55)-(56).

evaluate_ml_corrected.py
    پیش‌پردازش، آموزش چهار مدل، انتخاب مدل و ارزیابی شکاف اصلاح‌شده.

repeated_ml_metrics.py
    ارزیابی پنج تقسیم مستقل با ابرپارامتر ثابت.

audit_fast_solver.py
    مقایسه‌ی حل‌گر سریع با P2 دقیق.

audit_label_quality.py
    ممیزی کیفیت برچسب‌های ارتفاع.

benchmark_gap1.py
    مقایسه‌ی Fixed Hmin، Fixed Hmax، Algorithm 1، Algorithm 2 و SVR+P2.

verify_gap1.py
    آزمون معادلات، PSD، توان هر آنتن و سازگاری روش‌ها.

validate_report_claims.py
    تطبیق اعداد گزارش و ارائه با JSON/CSV ذخیره‌شده.

render_ml_figures.py
    تولید شکل‌های نهایی ML از خروجی‌های ذخیره‌شده.


ترتیب اجرای پیشنهادی
--------------------

بررسی سریع توسط استاد:

1. نصب requirements.txt
2. بازکردن 02_Complete_ML_Analysis.ipynb
3. اجرای سلول‌ها از ابتدا به ترتیب
4. ثابت نگه‌داشتن همه‌ی RUN_* روی False برای نمایش سریع نتایج ذخیره‌شده
5. در صورت درخواست بازتولید کامل، فعال‌کردن هر RUN_* به‌صورت جداگانه

تولید مجدد دیتاست فقط در صورت درخواست:

1. بازکردن 01_Dataset_Generation.ipynb
2. تنظیم RUN_ONE_CHUNK=True
3. اجرای مرحله‌ای تا رسیدن به تعداد نمونه‌ی مورد نظر
4. سپس اجرای نوت‌بوک 02


وضعیت تکمیل پروژه
-----------------

برای دامنه‌ای که در گزارش ادعا شده، کد کامل است:

- مدل ریاضی Kang و قیود P1/P2؛
- Algorithm 1 و Algorithm 2؛
- تولید داده‌ی فیزیک‌محور و بازتولیدپذیر؛
- چهار مدل ML و انتخاب منصفانه؛
- ممیزی داده، حل‌گر و برچسب؛
- ارزیابی شکاف تابع هدف؛
- مقایسه با مقاله روی شبکه‌ی 0.1 درجه؛
- شکل‌ها و آزمون خودکار ادعاها.

موارد زیر عمداً به‌عنوان کار آینده گزارش شده‌اند و نباید انجام‌شده ادعا شوند:

- داده‌ی واقعی و اعتبارسنجی OOD؛
- منحنی یادگیری تا 4000 نمونه؛
- پیش‌بینی مستقیم ماتریس covariance؛
- گواه رسمی بهینگی سراسری برای ارتفاع پیوسته.

نکته‌ی مهم:
فایل قدیمی HANDOFF.md و بسته‌های قدیمی Claude منبع نهایی نیستند و نباید به
استاد تحویل داده شوند. اعداد و تنظیمات معتبر در همین نوت‌بوک‌ها و خروجی‌های
همراه قرار دارند. مدل نهایی RBF-SVR دارای C=300، gamma=0.03 و epsilon=4 است.
